### Hi, I'm Cj Carito 👋

Based in Quezon City, Philippines. I build small, practical tools — mostly in Python, with Flask and Streamlit for the front ends — and I like squeezing real functionality out of free-tier infrastructure rather than reaching for paid services by default.

Portfolio: [civarry.github.io](https://civarry.github.io/)

#### What I work on

A mix of utilities and experiments: diff/comparison tools, file-processing scripts with small GUIs, Telegram bots, and web apps that started life as a Streamlit prototype and got rebuilt in Flask for more control over layout and deployment. Some pinned examples:

- **CodeDiffChecker** — a Flask app that compares two text files line by line and renders the differences in a searchable table.
- **file_splitter** — a GUI tool for splitting large files into smaller chunks and reassembling them.
- **my-portfolio / civarry.github.io** — my personal site, an interactive constellation of my repos connected by embedding similarity.
- **ReviewAIFlask** — a Flask remake of an earlier Streamlit review-AI project, rebuilt to get past Streamlit's layout limitations.

#### How I work

I favor shipping something working over something perfect, then iterating — a lot of these repos started as a quick script and grew real features once they proved useful to me. I'm also experimenting with agent-assisted workflows (Claude Code) for both building and maintaining projects, including the audit tooling that keeps this profile and its repos documented.
